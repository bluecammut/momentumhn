# Material de entrada para el sitio de Momentum

Deja aqui todo lo que ya existe. El sitio se construye a partir de esto.

- logo/       Logo en el mejor formato que tengas (SVG ideal, PNG con fondo transparente sirve).
              Si hay version clara y oscura, las dos.
- textos/     Descripcion de la empresa, servicios, mision, cualquier pitch ya escrito.
              Formato libre: .md, .txt, .docx, .pdf.
- clientes/   Lista de clientes o casos que SI se pueden publicar. Logos si los tienes.
- colores.md  Codigos hex de la marca, o una imagen de referencia si no los sabes.
